 I designed and implemented a linear regression model with l2 regularization from scratch. I used a kaggle notebook 
and the  housing prices dataset for my code, and used standard data preprocessing techniques to handle non numerical and missing data .
I participated in the housing prices competition to validate my performance and currently rank 1700/4100, with a
mean absolute error of about $16800 for each house. I am currently working on elevating my project  further by implementing bayesian 
optimization for hyperparameter tuning without the aid of external machine learning libraries.
