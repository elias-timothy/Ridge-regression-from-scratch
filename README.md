I designed and implemented a ridge regression model with bayesian hyperparameter optimization from scratch.
I used a kaggle notebook and the kaggle housing prices dataset as well as standard data preprocessing techniques to handle non numerical and missing data . 
As of September 19, 2026, the code effectively maximizes the acquisition function and produces intelligent queries for learning rate and ridge parameter.
